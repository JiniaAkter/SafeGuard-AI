# SafeGuard-AI
SafeGuard AI is a proposed project idea exploring how existing AI technologies, smartphones, and smartwatches can be combined to support potential violence detection, secure evidence preservation, and emergency response.

## About the Project

SafeGuard AI is a proposed university project idea that explores how existing artificial intelligence and audio-processing technologies can be integrated with devices that people already own to provide discreet safety support.

The concept focuses on identifying potential violence-related indicators from audio, securely preserving incident evidence, and supporting emergency communication with trusted contacts.

The project does not aim to develop a new AI model or dedicated hardware. Instead, it explores the integration and evaluation of existing AI technologies using smartphones and smartwatches.

SafeGuard AI is currently a project concept/prototype proposal and is not a completed or production-ready safety system.
